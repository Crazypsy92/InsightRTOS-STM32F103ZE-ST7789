# 实时性诊断

## 工作实例及配置

每个用户代可配置启停、名义周期（Tick）、执行预算（DWT 周期）和相对截止（Tick）。0 表示该参数未配置。周期用于描述调用者的释放计划，内核不会因周期自动生成 job。任务可仅启用驻留、READY 和 BLOCKED 测量。Idle 不接受任务预算。未配置预算或期限的任务对应指标为 N/A。

每代最多一个活动 job。线程生产者调用 job_release(target) 标记 release；目标线程调用 job_complete(job_id) 标记完成。已在运行的任务释放时，首次派发延迟定义为 0。外部线程可在通知前为目标标记 release，以包含真实排队延迟；两次调用之间调度仍可发生，诊断记录实际顺序。ISR 没有第一版 job API。release 重叠返回 STATE 并计拒绝，旧 ID 不会结算新 job。同代停启不重置 ID；任务退出时活动 job 标记 aborted 并计数，回收后用新 generation 清空记录。未发布、旧代及不受监测的任务不能结算。参考 [公开 API](public_api.md)。

## 时钟和统计定义

| 数据 | 时钟和计算 |
|---|---|
| 内核顺序、相对截止及释放到首派发/完成 | kernel Tick，ZET6 100 Hz。RT 启用后按 SysTick 递增维护扩展 tick，采样点与内核 tick 提交同锁。首派发指 C 提交边界，另计 wake/ready→dispatch 的驻留等待 |
| 实际驻留运行周期 | DWT CYCCNT，在 C 切换提交按出入任务对累计上一个驻留段。同任务选择不另起段。首次从既有 SVC 调用的 C tick 启动函数附近建基线，首段带启动边界偏差。当前段在只读快照中补上非重复虚拟增量 |
| 最大响应延迟 | 本代所有有效 job 的 release→首次被选中 Tick 上限，另报 READY→提交的最大 DWT 周期，包含抢占后的再次就绪等待 |
| 最大阻塞时长 | 从实际进入 BLOCKED 到解除等待并发布 READY 的 DWT 差，包括合法 early grant、timeout、cancel 和普通 Delay，保留最大值对应等待类别。未解除的阻塞可以显示当前值，不更新闭合最大值 |
| 预算超限 | 当前 job 的累计驻留周期减 release 时累计值，严格大于已配置预算判超。完成时最多计一次，运行中仅标当前状态。显示口径为驻留预算 |
| Deadline Miss | 完成 Tick 大于 release + deadline 时结算一次；未完成超过边界显示 overdue，不累加每 Tick 的次数。恰好到期完成算按时。aborted 单列；未观察到 job release 时不能判失败 |
| 独立参考 | TIM2 1 ms 用作板级采样/校时及实验对照，继续用于 KEY 和应用延时。内核截止期不依赖 TIM2 |

驻留周期是切换边界与已选任务关联的 CPU 时钟读数。它包含期间发生的 ISR、部分上下文/诊断开销。被其他任务占用的区间不会计到原任务。第一版将纯 Thread CPU time 标记不可测，避免把 ISR 误称任务执行。只有在已覆盖的 IRQ 和异常边界、独立测量源及误差预算成立后，才另定义净线程周期。WFI、调试器暂停与 DWT 时钟停走在板上需测定，不能用局部 DWT 推导墙钟或 CPU 占用率。导出含 HCLK、计量模型、可用性和时代标识。

## 回绕、故障和精度

在原锁内用 uint32 差值延伸 DWT 到 64 位。72 MHz 时一个低字周期约 59.65 秒。在有活动监测时，利用 SysTick 心跳采样，正常每 10 ms（并在任务边界采样）。单次跨回绕可恢复，前提是两次采样之间实际推进小于一整圈。SysTick/TIM2 的软件计数也会因长时间中断屏蔽或停止而失真，无法独立排除多圈。长关中断、外部暂停、时钟切换或重复初始化后，若已知采样间隔无保证则使测量时代失效、累计 invalid segment/job；经重新建立时代后恢复。对未被观测机制识别的长暂停不承诺有效数据。无可用 DWT 的端口可继续报告可信的 Tick 指标，周期值和驻留预算为 UNAVAILABLE。

Tick 的量化单位为 10 ms。可用的同一计时域内，差值采样量化约一 Tick，另外有 SysTick 投递抖动和丢 tick 的误差。若采样条件无效，质量标志在统计输出可见。DWT 一周期约 13.89 ns 是分辨率；Hook 到真正异常返回/IRQ 的差异以及测量自身开销通过板上 A/B 量化。软件不能用该分辨率声明绝对误差。计数和累计采用饱和或时代失效标志，报告不可恢复的间隔与无效 job 数，按有效样本统计。环丢失量与该测量质量分别报告。

## 热路径与辅助状态

复用任务发布、ready/block/wake、统一 IPC 完成及调度 C 提交点。原任务退出生命周期在同锁封存活动 job，slot 新代发布后清除统计。tick 心跳只推进时钟及质量状态，不扫描 8 个任务或格式化。快照锁内读取一代及端点，输出最多一个结构。当前还未闭合的驻留或 overdue 作为视图计算；不会写回采样计数。所有超限用于报告，优先级、调度、等待参数不由诊断修改。
