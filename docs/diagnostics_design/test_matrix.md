## 跨模块与回归判据

- 各开关 OFF、Trace-only、单开、双开、全开。Debug/O2 比较任务序列、PI 传播、owner/队列、错误码和截止行为。以原测试 ID、断言和基线比较防止选择器语义改变。保留旧 Trace 格式文件。
- Host 在 IRQ-unmask 边界注入调度、grant/cancel 及复用，证明窗口元数据与记录、边与顶点、tick 与统计同批一致，覆盖调用者缓冲检查。输出质量标志及丢失数有可重放 oracle。
- 新固件埋点预算同时满足实际资源、最坏临界区增量和原五页面性能。实机观测窗口为连续自由运行 60 秒，调试断点只在窗口之外使用。保存硬件配置、时基、任务进度、页面/按键/LED 用户观察、SPI/DMA 错误、事件覆盖、栈 guard、已观察故障。
- 受控故障注入使用独立任务、锁和静态栈，提供有限等待或者同代监督取消及明确退出清理。禁止在应用 SPI3/键盘链制造无限环。脚本验证 PSP/MSP 与资源后才进入实际试验。任何板上部署另行授权。
