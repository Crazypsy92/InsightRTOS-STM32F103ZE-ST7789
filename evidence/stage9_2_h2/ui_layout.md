# Stage 9.2-H2: 中文单屏综合验收看板排版规范 (UI Layout)

## 一、界面整体架构 (240×240 IPS)

单屏综合看板由 15 行等高文本区域构成（行高 16 像素，总高度 15 × 16 = 240 像素）：

```text
Row 00 (y=  0): InsightRTOS     系统运行      (青色)
Row 01 (y= 16):                              (空行/黑底分隔)
Row 02 (y= 32): 任务状态                      (黄色标题)
Row 03 (y= 48): > KEY        阻塞   P5        (当前选中: 黄色高亮)
Row 04 (y= 64):   CTRL       阻塞   P4        (未选中: 白色)
Row 05 (y= 80):   LCD        运行   P2        (未选中: 白色)
Row 06 (y= 96):   MON        阻塞   P1        (未选中: 白色)
Row 07 (y=112):                              (空行/黑底分隔)
Row 08 (y=128): 当前任务: KEY                 (黄色)
Row 09 (y=144): 运行次数: 12                  (白色, 双击切换为: 任务状态: 阻塞)
Row 10 (y=160): 优先级: 5/5                   (白色, 双击切换为: Task Gen: 1)
Row 11 (y=176): 死锁诊断: 无死锁              (绿色安全, 异常或有环显示红色)
Row 12 (y=192): Trace: 10754                  (白色因果追踪事件序号)
Row 13 (y=208): 错误: 0    长按: LED          (白色/错误时红色)
Row 14 (y=224): 单击选任务  双击查询          (灰色操作指引)
```

---

## 二、双击详情切换规范

- **默认视图 (模式 0)**：
  - Row 08: `当前任务: <NAME>`
  - Row 09: `运行次数: <COUNT>`（读取 `task_runs` 或 `key_task_events`）
  - Row 10: `优先级: <BASE>/<EFFECTIVE>`（读取任务快照优先级）
- **详情视图 (模式 1)**：
  - Row 08: `当前任务: <NAME>`
  - Row 09: `任务状态: <就绪/运行/阻塞/退出>`（实时调度状态中文显示）
  - Row 10: `Task Gen: <GENERATION>`（任务代次编号）

## 三、差分显存与无闪烁渲染机制

1. **行缓冲与字符串补齐**：每一行利用 `CONS_LINE_MAX_BYTES` (64 字节) 进行 UTF-8 格式化，末尾自动计算像素宽度，以 ASCII 空格补齐至 240 像素。
2. **零开销静止**：当某一行字符与颜色相比上一帧无变化时，`strcmp` 命中，直接跳过 SPI 传输。
3. **消除清屏频闪**：系统仅在首次初始化（`entering == true`）时执行一次全黑清屏，后续所有刷新均为局部差分重绘，彻底消除画面频闪。
