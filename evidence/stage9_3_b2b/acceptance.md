# Stage 9.3-B2b 实机验收

**HARDWARE_MEASURED**。固件基线 `9ea65183e081aca0da80eac1253a5626a0b730b3`。STM32F103ZET6 以 72 MHz 实跑 O2 RT OFF 与 RT ON，各 62.000 秒，分别使用相同的 600 次按键刺激。每轮 14 份运行健康记录，四业务任务与 Idle 均有调度记录。

下表为扣除每轮 9 周期空调用开销的 DWT 周期。最大值为本轮观测值。

| 路径 | 每配置样本 | OFF 平均 / 最大 | ON 平均 / 最大 | ON−OFF 平均 / 最大 |
|---|---:|---:|---:|---:|
| PendSV C | 14,875 | 1,445.4 / 1,695 | 1,979.5 / 2,396 | +534.1 / +701 |
| SysTick C | 6,200 | 1,292.6 / 3,307 | 1,929.1 / 4,360 | +636.6 / +1,053 |

ON 的 Job Release、Complete、Snapshot 各 6,199 样本，平均分别为 841.1、759.1、439.0 周期。完成 Job 为 6,199，最终无活动 Job、失效标志、miss 或 overrun。

**两条路径的观测峰值在 OFF 已超参考值**。PendSV C 的 800 周期和繁忙 SysTick C 的 2,000 周期目标在这组负载下未达到。该结果已分开记录基线和 RT 增量，未调整生产调度路径。峰值归因边界、原始统计、微秒换算及未测项目见 [测量报告](timing_measurements.md)。

两套固件独立读回通过，页 0–30 擦除后空白与写入后的 FF 尾部检查通过，Option Bytes 前后一致。两轮均接收并结算 600 个事件，队列满、拒绝、遗漏或 ACK 失败计数均为零。四任务与 Idle 栈 guard 完整，未观察到断言、MCU 故障或 LCD/SPI/DMA 传输错误。RT ON 的 DWT 及任务快照有效，SysTick 配置及实测 Tick/TIM2 增量一致。

应用 Host 9/9，历史 RT 9/9，原 Job 77 项及 DWT 失效回归 53 项通过。两个 O2 测量预设和正常 O2 Trace 均构建通过，正常镜像无测量或注入符号。连续 PRIMASK 全窗、物理 IRQ 响应、MSP 水位及 WCET 未测。开发板最终保留 RT ON 测量固件。
