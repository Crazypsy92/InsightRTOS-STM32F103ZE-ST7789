# Stage 9.3-B2b 设备与测量方法

## 可测边界

- PendSV 采样仅当 IPSR 表示 PendSV。第一次从 Thread 建立调度上下文的调用不计入。周期计数包住无内联的调度 C 函数，包括现有断言、Trace、ready queue 操作，以及 RT ON 的 ready/switch hooks。起止点均在现有汇编的 PRIMASK 屏蔽区内。汇编保存和恢复 PSP/R4–R11、异常自动入栈与返回在采样区间外。RT ON−OFF 比较的是整个 C 路径，包含所有该路径上启用的 RT hooks。
- SysTick 从调用 rtos_tick_handler() 前到返回后。包括临界区、Tick 推进、调度 Tick hook、到期等待者处理和唤醒。恢复 PRIMASK 后若有更高优先级异常在结束读数前运行，它的周期可能计入样本。
- Release、Complete 和 Snapshot 在 Controller Thread 从调用前量到返回后。含各 API 的内部检查及临界区，若调用期间被抢占，读取的是经过的 DWT 周期。RT OFF 没有这些 API。
- 起止读数直接读 DWT CYCCNT，编译器屏障约束移动。使用每个区间的无符号 32 位差，单区间远小于一个回绕周期。每路径只有一个写者，所有有效样本累计计数、64 位和、min、max。统计写入在结束读数后；其额外时间可能影响后续任务相位。无需在 ISR 输出、分配内存或通过主机采样填入样本。
- 每套固件分别记录 64 对直接空读和 64 个同型无内联空调用，校准时临时屏蔽 IRQ。空调用包含两读和一次 BL/return。表中同时保留原始值和减去该轮最小空调用开销的估计。72 MHz 下微秒等于周期除以 72。min/mean/max 由全部记录计算，固件未保存逐次周期样本，因此不计算 P99。
- 未改变 SVC/PendSV 汇编。连续 PRIMASK 窗口整体未插桩，PendSV C 子区间只是其一部分；未用外部仪器测 IRQ 响应延迟。样本峰值受本轮负载和插桩影响，WCET 未认证。

## 成对负载与复现

两个 O2 预设分别为 DISPLAY_RTOS_O2_Timing_Off 和 DISPLAY_RTOS_O2_Timing_On。都继承 DISPLAY_RTOS_O2_Stress，启用相同 Trace/Explain/DL、4 个现有业务任务和 Idle、相同的 72 MHz 与外设。唯一区分 RT 执行模式的配置是 INSIGHT_DIAG_RT。正常镜像禁用 INSIGHT_TEST_TIMING，未链接计量符号。专用 profile 沿用 TIM2 ISR 的合法注入路径，设定 10 Hz 共 600 次短键事件，62 秒计数窗口自动结束，未改变任务数量或优先级。RT ON 中 Controller 每周期发布、读快照，并在下一次循环完成该 Job；此测试生命周期是 RT ON 路径的组成部分。

用 CMake 对这两个预设分别配置及构建，冻结有符号 ELF 与同次导出的 BIN/HEX/MAP。用独立 ELF/HEX 解析工具核查物理 Flash 段、向量和宏，保存经批准的 firmware-audit.json。实机脚本 tests/hardware/run_timing.sh 要求已独立核验的旧镜像区间的读回文件与空白暂存目录作为参数，运行时还要逐字节重新核对板上现有区间，才能进入页 0–30 擦写。脚本核验固定 ST-Link、MCU/UID、Flash 2 KiB 页、Option Bytes、保护和读回。另用 MEM-AP live 会话每隔约 5 秒读取 DWARF 校验后的健康快照；统计窗口由固件自主推进，不靠 SWD 暂停或轮询达到时长。

Host 使用 scripts/test/run_host.sh、scripts/test/run_rt_host.sh。正式 O2 Trace 有单独构建和 nm 负检查。本轮生产逻辑未变，没有重复执行独立内核 360 项。本阶段不测 MSP 水位。

ON−OFF 的 PendSV C 最小/平均/最大统计差为 +360 / +534.13 / +701 cycles，平均 +7.419 µs；SysTick C 为 +574 / +636.57 / +1,053 cycles，平均 +8.841 µs。差值来自两次完整窗口的汇总，未逐样配对。RT ON 有活动 Job 参与 Tick 扫描。两轮 PendSV 样本数一致，Idle 调度分别 3,130 和 3,129。

OFF 峰值已经超过两个参考预算。PendSV OFF 区间包含任务栈/队列状态校验、ready queue 和可解释 Trace 的多条记录；SysTick OFF 的到期等待队列可重复唤醒任务，且在解屏蔽后可能计入更高优先级异常。RT ON 额外包含 ready/switch 计量和 RT Tick 的固定槽扫描及活动 Job 更新。以上由调用路径核对确定，未把单独函数或某次峰值的周期拆分归因。

## 部署与限制

板卡为已记录的 512 KiB ZET6，ST-Link 序列号 190057000D0000393333574E。OFF 镜像 49,724 B，尾部 13,764 B 为 FF；ON 镜像 53,552 B，尾部 9,936 B 为 FF。两个起始地址均为 0x08000000，擦除范围均为 [0x08000000, 0x0800F800)。

最初 950 kHz SWD 的只读预检在 0x08003000 中止，改为 480 kHz 后通过。OFF→ON 切换时运行中只读预检有 4 B 在 0x0800B4B0 处读成零，脚本在擦除前中止。停止运行后重读，完整区间与已经验证的 OFF 镜像逐字节一致，才执行 ON 部署。两次拒绝日志保留。两次正式 62 秒采样窗口均自由运行。

完整连续 PRIMASK 屏蔽、物理 IRQ latency、MSP 水位为 NOT_TESTED。P99 未采集。实时计量上限未获证，正式显示画面未进行人工目视复测。
