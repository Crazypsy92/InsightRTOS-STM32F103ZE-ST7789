# Stage 9.2-H4: ST7789 240×240 单屏界面精简与布局规范

## 一、界面修订背景

根据 GitHub Issue #3 要求：
1. **精简屏幕显示**：
   - 彻底删除第 11 行的 `Trace:<数字>` 显示及 `display_ui.c` 中相关的 `rtos_diag_trace_info` 界面调用。
   - 底层内核 Trace 机制（`Middlewares/InsightRTOS/kernel/trace.c`、`rtos_trace.h`、`INSIGHT_TRACE_ENABLED`、`INSIGHT_DIAG_EXPLAIN`）**100% 完整保留**，不做任何破坏性裁剪。
   - 原第 11 行替换为按键处理结果统计：`事件: 成功:<success> 失败:<failure>`（有重试时显示 `重试:<retry>`）。
   - 精简第 12 行详情显示：去除冗余的 generation 代数及 tick，仅显示清晰的 `详情: 运行次数: <runs>`，关闭详情时保持空白隔离。
2. **字模库补全**：
   - 扩充 16×16 点阵字模库，新增 `'成'`, `'功'`, `'失'`, `'败'`, `'重'`, `'试'`, `'次'` 等字符，字模总数达到 143 个。
