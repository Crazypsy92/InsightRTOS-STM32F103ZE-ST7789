# Stage 9.2-H3: 单屏中文界面布局与点阵规范 (UI Layout Specification)

## 一、屏幕规格与排版约束

- **显示硬件**：ST7789 IPS LCD，分辨率 **240 × 240 像素**。
- **驱动接口**：SPI3（72 MHz / 2 = 36 MHz 预分频）+ DMA 自动突发传输。
- **字模体系**：
  - 中文字体：16×16 点阵，单色 1 bit/pixel（32 字节/字），宽度 16 px，高度 16 px。
  - ASCII 字体：8×16 点阵（`ASCII_Font16`），宽度 8 px，高度 16 px。
  - 屏幕纵向容量：`240 / 16 = 15 行`（Row 00 ～ Row 14，行高严格 16 px）。
  - 屏幕横向容量：最多容纳 15 个汉字（15 × 16 = 240 px）或 30 个 ASCII 字符（30 × 8 = 240 px）。
- **刷新策略**：差分局部行重绘（`previous_cons` 缓存逐行比对），仅文本或颜色变动的行触发 SPI/DMA 发送，未变动行零总线开销。

## 三、任务中文职责描述映射（第 8 行）

单击单按键依次循环选中 4 个系统任务，并在 Row 08 动态显示其真实职责：

1. **KEY (Task 0)**：`选中: KEY 接收按键事件`
   - 像素宽度：48 + 32 + 96 = **176 px**（<= 240 px）。
2. **CTRL (Task 1)**：`选中: CTRL 处理事件/控制LED`
   - 像素宽度：48 + 40 + 128 = **216 px**（<= 240 px）。
3. **LCD (Task 2)**：`选中: LCD 更新中文屏幕`
   - 像素宽度：48 + 32 + 96 = **176 px**（<= 240 px）。
4. **MON (Task 3)**：`选中: MON 状态错误监测`
   - 像素宽度：48 + 32 + 96 = **176 px**（<= 240 px）。

## 四、事件链路与留痕时序（第 2 行）

- **处理中**：仅显示已实际发生的链路节点：
  - 中断识别完成：`链路: 识别`
  - KEY 任务出队：`链路: 识别>KEY`
  - Controller 任务决策：`链路: 识别>KEY>CTRL`
  - LCD 任务重绘完成：`链路: 识别>KEY>CTRL>LCD`
- **留痕窗口（~2 秒）**：
  - 当 `elapsed_since_done < 2000 ms` 时，保持显示 `链路: 识别>KEY>CTRL>LCD`（绿色）。
  - 当 `elapsed_since_done >= 2000 ms` 时，自动平滑退回 `链路: 待机`（灰色）。
  - 任务无需睡眠等待留痕，所有任务立即返回 BLOCKED 等待下一队列事件，实现非阻塞留痕。
