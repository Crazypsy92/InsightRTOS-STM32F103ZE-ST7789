# Stage 9.4-I ST7789 实际面板与 TX DMA 验收

**STATUS: PASS**。板卡为 STM32F103ZET6。现场操作人确认断电拆除 PB5→PB4 回环并恢复 ST7789 正常接线。SWD 身份与保护状态匹配，烧录前另确认 PD11 空闲为高。诊断仅由现有 LCD Task（slot 2）调用生产驱动，沿用现有队列和优先级。

## 面板目视

现场操作者由对话回传结果。现场确认纯色轮换、四色象限、横竖色条与下方帧号出现，10 分钟诊断期间未见错色、错位、花屏或残影。诊断退出及恢复冻结正式固件后均确认原 InsightRTOS 信息页显示正常。未采集照片。 同一画面下方追加帧号属于局部刷新，下一轮再更换整个底色。实际 SCK 波形 **NOT MEASURED**；由 APB1 36 MHz、BR=0 和 Mode 0 寄存器推导 18 MHz。

- 实际 SPI3 TX DMA **235,362** 笔，轮询 **93,206** 笔，命令 **25,393** 笔。DMA 分桶 16–63 / 64–239 / 240 / 241–479 / 480 / >480 B 为 [123904, 2688, 26880, 168, 81600, 122]。实际行源 CMAR 0x200002A8，CNDTR 480→0，清理前 ISR 0x70，TX TCIF=1、TEIF=0。
- 480 B 像素阶段 PD11=0、PD12=1，RX 请求与通道关闭。排空时 SR=0x43，写返回 SR=0x02。自然 OVR 在 235,362 个 DMA 收尾中被观察到，返回后全部清理。片选次数与释放次数均为 67,728，释放后总线 READY、owner=NULL、depth=0。单次最长占有 **58.60 ms**。
- Controller、LCD、Monitor 在所有分钟区间持续推进。KEY 空闲时阻塞等候输入，计数为 0；原采集器把 KEY 视为周期任务，误判停滞并停止恢复流程。保留首次失败日志后，以原始快照离线复核连续时段，并在恢复前确认 3 个实体 KEY 事件全部通过 KEY→Controller→LCD→ACK。队列观测最大深度 [0, 0, 0, 1, 1]；初始化、传输、溢出、不变量、LL 错误和恢复计数均为零。四业务任务与 Idle 的栈 guard 完整，采样无故障和断言。

## 构建与正式固件恢复

- Host **478/478**；新增五个观测解析反例与真实采集回放通过。ARM Debug/O2 构建、ELF/BIN/HEX 一致性和正式 ELF 符号隔离通过。
- O2 镜像 56,736 B，静态 SRAM 51,632 B（含 4 KiB MSP）。Debug 镜像 79,824 B，静态 SRAM 51,624 B，超出本轮页 0–30 授权容量，仅生成软件构建产物。
- 仅擦写页 0–30，夹具和正式 O2 均完成独立读回。冻结正式 O2 的 63,488 B 授权区与测试前逐字节一致，Option Bytes 不变。正式固件复位后 Monitor 序号 4→8，Tick 210→550。
- 物理 SCK 波形未测。本轮不注入 TEIF、永久 BSY 或不可清除的 OVR。
