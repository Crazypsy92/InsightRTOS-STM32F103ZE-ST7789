# 两次板载 RESET

**PASS**。首次用户实体复位时，调试器在原 Reset_Handler（PC 0x080010B8，MSP 0x20010000）捕获目标。VTOR=0 的 Flash 别名向量与 0x08000000 的向量内容一致。随后观察到 SVC、PendSV、四个任务和 Idle，再释放目标进入后续检查。

60 秒窗口后关闭复位捕获状态，用户执行最后一次板载 RESET 并回复「正常」。最终独立 MEM-AP 检查在一个跨复位边界的复合样本中捕获 DHCSR S_RESET_ST=1。该样本的前半段仍读取到上次运行的 ready=1 和 Tick 24,402、TIM2 244,047，后半段栈 guard 读取于复位初始化窗口成为零。原观察脚本因此提前结束，原始记录予以保留。

复位后重新只读采样，两份完整样本的 guard 均为 0xDEADC0DE，CFSR/HFSR 和断言行号均为零，ready=1、welcome_shows=1。Tick 7,143→7,355，TIM2 71,440→73,556，均小于复位前计数且重新递增。动画页刷新 2,100→2,171。最终 Option Bytes 与操作前逐字节一致。未发出软件复位，关闭自己的 MEM-AP 会话时目标仍自由运行。
