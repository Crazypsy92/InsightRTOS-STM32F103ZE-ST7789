# 后续 STM32F103ZET6 验收计划

当前记录 **HARDWARE NOT EXECUTED**。固件包与用例计划已备齐，本阶段保持 C2 板上固件。下阶段需单独授权 C3 版本与页范围后再操作。

## 固件准入

1. 默认选 O2，使用包清单核验 ELF/BIN/HEX/MAP。BIN 58,804 B，SHA256 为 `bf85e29f09ae20a2fec28fc106e1a8cc6614b47af379702369595c0789e460dc`。
2. 使用 ST-Link `190057000D0000393333574E`，只读比对 C2 的 MCU IDCODE、CPUID、UID、容量、电压和 Option Bytes。确认 512 KiB、2 KiB 页、保护状态一致。读取计划范围，并核对是否存在与基线不符的数据。
3. O2 有效写入为 `[0x08000000,0x0800E5B4)`，计划页 0–28，擦除末端 `0x0800E800`。独立读回 58,804 B，逐字节及 SHA256 对照，确认后续 588 B 为 FF，Option Bytes 前后一致。禁止全片擦除与更改保护。Debug 需要页 0–37，范围扩大须另行核验和授权。
4. 无调试入口断点时用板载 RESET 启动，确认欢迎页、原四页、第五页动态计数、短按和长按/LED、至少 100 次切页。保存目视的用户确认或照片，并记录原始 Task、Queue、Tick、DMA 计数。

## SPI 边界和故障

| 用例 | 测法及证据 | 通过条件 |
|---|---|---|
| 1 B、255 B | 位流记录或受控回环和原始帧统计 | 1 B 轮询，255 B DMA，内容正确，最后一个 SCK 后才释放 CS |
| 65,535 B，以及 65,536/131,071 B | 从下一阶段独立 HIL 测试镜像的 Flash 读取 TX 图案，逻辑分析仪在 PB3/PB5 及独立 CS 观测，记录长度及分块 | CNDTR 的 65,535+余数，整次 CS 持有，数据和顺序正确，在实际时钟和记录的开销下无误超时 |
| 双工及 RXNE/OVR | 回环或 SPI 参考从机，使用可容纳的静态 TX/RX 缓冲；正常/故障后比较首尾字节 | 无首字节偏移或静默数据损坏，故障时 ERROR、release、recover 契约成立 |
| 恢复与超时 | 独立 HIL 镜像或可撤销设施触发 DMA TE、缺 TC、卡 TXE/BSY；逐次记录 SR、DMA ISR/CNDTR、返回码、恢复计数 | 有界超时，DMA 请求与通道关闭，恢复失败有明确错误码，同条件解除后下一次 acquire 和事务成功 |
| 抢占 | 捕获长块 CS 窗口及 KEY/Controller 运行标记，记录事件和计数 | LCD 调用尚未返回时，高优先级任务运行，后续 LCD 刷新与按键事件继续 |
| SCK | 示波器或逻辑分析仪在 PB3 测活动边沿间隔；采样率应明显高于 SCK | 实测接近 18 MHz，提供波形、测量误差和采样设置 |
| 稳定性 | 连续至少 30 分钟，切页及输入，记录四任务推进和 SPI/DMA 错误、HardFault、PSP 栈水位和 guard | 无异常停机、无非注入的传输错误或显示异常，所有启用栈 guard 完整，板载 RESET 后恢复 |

量产五页面固件没有超长块或故障注入入口，常规页面显示不能替代这些用例。独立 HIL 镜像尚未构建，需要未来授权和独立擦写审计。ZET6 64 KiB SRAM 无法在现有四任务布局中容纳单个超过 65,535 B 的 RX 缓冲。大块 TX 使用 Flash 静态图案，板上双工在实际可用 SRAM 内测试，超长双工的跨块数据通过本轮 Host 模型覆盖。没有仪器或不能注入的项应标记 **NOT MEASURED** 或 **NOT EXECUTED**，保留 C2 数据作为历史基线。
